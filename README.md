Sprint Django - Projetos e Tarefas

Sistema desenvolvido em Django para gerenciamento de projetos e tarefas.

o que foi utilizado:

- Python
- Django
- SQLite
- Git
- GitHub

Funcionalidades:

- Cadastro de projetos
- Listagem de projetos
- Edição de projetos
- Exclusão de projetos
- Cadastro de tarefas
- Listagem de tarefas
- Edição de tarefas
- Exclusão de tarefas
- Relacionamento entre projetos e tarefas
